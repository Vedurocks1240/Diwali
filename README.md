# Happy Diwali site (Vedansh Jain, Vedurocks)

## Change the names or wishes
Open `src/config.ts`, edit the text inside the quotes, save. That's it.

## Put it online (easiest way)
1. Create a free account at github.com and click **New repository**. Name it `diwali-site`.
2. Click **uploading an existing file**, drag in ALL files and folders from this project (not the zip itself), then click **Commit changes**.
3. Create a free account at vercel.com (sign in with GitHub).
4. Click **Add New > Project**, pick `diwali-site`, then click **Deploy**. Leave every setting as it is.
5. After about a minute Vercel gives you a live link. Share it!

## Run on your computer (optional)
Install Node.js, then in this folder run:
    npm install
    npm run dev
